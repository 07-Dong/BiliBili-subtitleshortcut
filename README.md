# BiliBili-subtitleshortcut
B站字幕快捷键

看视频的时候经常会有没有字幕的时候，这时候需要手动点击【字幕】-【中文（AI）】，如果很多视频都没有字幕的话手动点击的效率太低。

这个程序默认“、”为开启字幕的开关（如果有字幕功能的话），再次点击关闭。
使用教程简化版：
  1.关闭B站，确保程序完全关闭的前提下运行【启动.vbs】文件（这个过程可能需要几秒钟）
  2.正常情况下会生成【B站字幕快捷键】的快捷方式在根目录下，有需要把这个快捷方式放到桌面的CTRL+C,CTRL+V即可（不可直接推拽！！）
  3.以后每次首次打开B站前直接点击【B站字幕快捷键】，这样字幕快捷键功能才可正常使用，对其他功能目前测试毫无影响。
  
  上述操作如果有问题的详情见【使用说明.txt】文件，本项目支持自己修改按键，使用【改按键.bat】按照操作即可（若冲突按键不可修改，如“空格”改为字幕快捷键）
