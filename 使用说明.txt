========================================
     B站字幕快捷键 —— 使用说明
========================================


【这是什么】

给 B站电脑客户端加一个快捷键：按「、」开字幕，再按一下关字幕。

以前每打开一集视频，都要手动点一下播放器下面的字幕按钮。现在按一下
键盘上的「、」就行。

只对「有字幕的视频」生效。没有字幕的视频按了没反应，这是正常的。

不需要安装，不会修改 B站客户端的任何文件。


【怎么用】

第 1 步  解压
        把整个压缩包解压到任意文件夹（比如桌面）。
        注意要先解压，不要直接在压缩包预览窗口里双击运行。

第 2 步  解除文件锁定（重要，容易漏）
        从网上下载的文件，Windows 会加"已阻止"标记，不解开可能被拦。
        右键点击 runtime 文件夹里的 node.exe → 选"属性"
        如果窗口底部有"安全：此文件来自其他计算机，可能被阻止"，
        勾选下面的"解除锁定" → 确定。
        如果提示多个文件，可以全选后一起操作。

第 3 步  完全退出 B站客户端
        注意右下角托盘区的 B站 图标：右键 → 退出。
        只关窗口不算退出，程序还在后台跑着。

第 4 步  双击"启动.vbs"
        B站客户端会自动打开。**不会有黑窗口弹出来**，这是正常的。

第 5 步  进视频，按「、」
        打开任意有字幕的视频，按键盘上的「、」键开字幕。
        再按一下关闭。


【日常使用】

· 以后每次都用"启动.vbs"进。直接点原来那个 B站 图标，快捷键不生效。
· 想确认状态，双击"查看状态.bat"。
· 想关掉快捷键，双击"停止.bat"。


【放到桌面】

第一次运行成功后，文件夹里会多出一个"B站字幕快捷键"快捷方式，
图标就是 B站 的图标。把它拖到桌面，以后双击它就行。

拖的时候注意：Windows 在同一个磁盘内拖动默认是"移动"，
拖走后文件夹里就没有了。想保留一份，请用**右键拖动 → 选"复制到当前位置"**，
或者按住 Ctrl 拖。

快捷方式里存的是文件夹的绝对路径。如果整个文件夹被挪了位置或改了名，
快捷方式就会失效，得重新生成一个（删掉旧的，双击一次"启动.vbs"）。


【常见问题】

问：双击了没反应，客户端也没打开？
答：多半是被杀毒软件拦了。"启动.vbs"用的是隐藏运行方式，
    杀软对这类行为比较敏感。把整个文件夹加入信任区再试。
    另外可以双击"启动.bat"看看有没有报错 —— 它是可见的，
    会把每一步都打在黑窗口里。

问：双击快捷方式，完全没动静？
答：最可能的原因是 B站 已经开着（哪怕是你自己从原图标打开的）。
    本程序必须在启动时给客户端开一个调试端口，事后补不了。
    请先完全退出 B站（含右下角托盘图标），再双击快捷方式。

    另外：这个程序是**隐藏运行**的，出问题不会有弹窗，
    原因都记在"配置\运行日志.txt"里。看不到动静时先去翻它。
    想直接看到出错信息，双击"启动.bat"，它会显示每一步。

问：按了没反应？
答：先双击"查看状态.bat"，按它显示的内容对照：

     显示「快捷键: 未注入」   → 后台程序没在跑，重新双击"启动.vbs"
     显示「有字幕: 否」       → 这个视频本来就没字幕，正常现象
     显示「连不上调试端口」   → 客户端不是从"启动.vbs"开的，重来一次
     提示"一直没找到播放页"   → 还没打开视频，打开任意视频就会生效

问：怎么看后台程序在干什么？
答：打开"配置"文件夹里的"运行日志.txt"，每次启动会重新写。

问：启动很慢 / 客户端半天不出来？
答：只有第一次慢（要在你电脑上找 B站 装在哪，约 4 秒）。
    找到之后会记下来，以后就是秒开。
    如果一直慢，删掉"配置\客户端路径.txt"让它重新找一次。

问：黑窗口一闪就没了？
答：说明运行环境有问题。重新解压一次，确认 runtime 文件夹里
    有 node.exe（约 88 MB）。

问：能用在网页版 B站 吗？
答：不能。只支持 B站 的 Windows 电脑客户端。

问：苹果电脑能用吗？
答：不能。只支持 Windows。


【想换个按键？】

双击"改按键.bat"，按一下你想用的键，就改好了。
改完要重新双击"启动.vbs"才生效。

注意：有些键被 B站 播放器自己占用了，比如空格（暂停）、F（全屏）、
M（静音）、D（弹幕）等。选这些键会导致一次按键触发两个功能，
所以程序会直接拒绝，并列出所有不能用的键。

想恢复默认的「、」键，也是双击"改按键.bat"，然后按一下反斜杠键
（回车键上面那个）。

也可以用记事本直接编辑"配置"文件夹里的"按键.txt"，里面写得很清楚。


【提示"没有找到 B站客户端"？】

先看看自动查找能不能搞定 —— 它会在四个地方找：正在运行的进程、
开始菜单快捷方式、注册表、常见安装路径。

都不行的话，按提示操作：
  1. 右键桌面上的 B站图标 → 打开文件所在位置
  2. 点一下地址栏，复制完整路径
  3. 粘进"配置"文件夹里的"客户端路径.txt"，保存
  4. 重新双击"启动.vbs"


【已知限制】

· 只支持 Windows 系统。
· 只能绑单个键，不支持 Ctrl+某键、Shift+某键这类组合。
· B站 客户端更新后，本工具可能失效 —— 因为播放器界面改版后，
  脚本就找不到字幕按钮了。这种情况只能等工具跟着更新。


【文件说明】

  启动.vbs          ← 日常用这个（无窗口）
  启动.bat          ← 排查用，能看见每一步输出
  改按键.bat        ← 换快捷键
  停止.bat          ← 关掉后台程序
  查看状态.bat      ← 出问题时排查用
  使用说明.txt      ← 本文件
  配置\按键.txt     ← 按键设置
  配置\客户端路径.txt ← 自动记录 B站 装在哪，一般不用管
  配置\运行日志.txt ← 每次启动重新写，排查用
  runtime\node.exe  ← 程序运行需要的环境（不用管它）
  src\              ← 程序本体（不用管它）
  status.js         ← 状态查看的实现
